# 实现过程与验证记录

日期：2026-11-05。

## 需求和判断

输入是三张上下拼接的参考图片：上半幅为原拓片，下半幅为带蓝色骨架、彩色节点和中心标记的分析图。目标是解释技术、寻找开源实现并验证复现路径。

根据边缘短分支、背景孤立节点以及第三张右侧裂纹同样生成骨架的现象，判断结果符合传统图像分割、细化、路径追踪与节点标注流程。该判断不能证明原作者实际使用了哪种算法。红、橙节点的原始含义也没有可靠图例可供确认。

查阅了 scikit-image、skeleton-tracing、sknw、Skan、CCSE、Make Me a Hanzi、Hanzi Writer 及 Potrace 的一手资料。最终采用 scikit-image 和 sknw 验证几何骨架路线。

## 输入准备

仅使用上半幅原拓片；下半幅分析图没有参与计算或训练。人工选定裁切框：

| 样本 | 原始尺寸 | 裁切框（左、上、右、下） |
|---|---|---|
| sample1 | 744 × 1478 | 12, 12, 732, 732 |
| sample2 | 744 × 1416 | 12, 12, 732, 701 |
| sample3 | 738 × 1466 | 12, 12, 726, 726 |

原始图片按原字节保存到 `data/original/`。`data/samples.json` 保存原附件名、相对路径、SHA-256 和裁切记录。原图仍保留其自身标记，处理区域不包含下半幅分析图。

## 基础实现

1. 灰度化并以 sigma=1 平滑，再用 Otsu 分割亮色前景。
2. 提供基础提取和轻度去噪两种结果。后者删除小连通区域、闭合微小缺口、填补小孔。
3. Zhang 细化生成单像素骨架；距离变换用于估计局部宽度。
4. 对短的端点—分叉边进行有限剪枝。
5. 使用 sknw 生成保留环、孤立点及平行边的无向多重图。
6. 导出 JSON、PNG 和嵌入原图的 SVG。展示用折线简化不覆盖完整路径数据。
7. 构建可切换样本、处理方式和显示层的交互页面。

## 检查中修正的问题

- 第三张最初裁切至 y=727，包含 y=726 的白色分隔线，造成底部横向伪骨架。检查该行像素亮度后，将下边界改为 726，排除分隔线。
- scikit-image 0.26 的 `binary_closing` 已弃用，替换为 `closing(..., mode='ignore')`，随后重新运行三张图。
- 查看器图例使用 `display:flex` 时可能覆盖 HTML `hidden` 的默认行为；增加显式隐藏规则，验证切到二值图后图例确实消失。

## 项目整理

将最初的会话输出整理为独立项目：

- 保存三张完整输入图片及裁切配置，消除临时附件路径依赖。
- 保持核心算法和结果字段不变；新增 Python 包元数据及 `hanzi-skeleton` 命令。
- 批量复现入口改为从脚本位置定位项目，消除当前工作目录依赖。
- 对比图字体增加回退策略，字体仅影响标题，不影响图分析。
- 将会话查看器导出后，整理为项目自己的精简页面外壳，保留图表片段作为编辑入口；重建时内嵌图像与数据。交互状态使用本地存储，页面不依赖 Codex 的技能目录、宿主接口或 CDN。
- 保留三组基础及清理结果，将每次运行的依赖版本写入 `results/summary.json`。
- 使用项目自己的 `.venv` 安装依赖并复现；虚拟环境、缓存和临时检查文件不纳入 Git。

## 验证范围与局限

已在原实验中检查三张图的叠加效果及交互切换。项目整理后的验证包括：三张原始输入摘要校验、六组结果的图引用和坐标一致性、与迁移前 JSON/二值图/骨架图对比，以及命令行入口运行。

项目整理后的实际验证结果：

- 从项目外的工作目录运行批量复现脚本成功。
- 六个完整 `graph.json` 与原实验逐字段相同。
- 24 张 PNG（每组 input、mask、skeleton、overlay）的像素数组与原实验相同。
- 六个 SVG 与原实验逐字节相同。
- 安装后的 `hanzi-skeleton` 命令成功处理图二，得到 88 节点、83 边、7 个连通分量。
- `pip check` 未发现依赖冲突。
- 浏览器成功加载独立页面，切换到图三／基础提取／二值图后显示 509 节点、305 边、219 个连通分量，骨架图例随显示层隐藏。
- 结果页面已内嵌全部数据，没有外部脚本加载或 Codex 宿主 API 调用。
- 本地 Git 仓库以 `main` 分支初始化，尚未创建提交或设置远程仓库。

这些检查验证迁移和几何输出的一致性，不等于书法笔画识别准确率。骨架仍有毛刺分支、裂纹和石花；简单剪枝也可能移除真实笔锋。当前没有人工标注的真实笔画、笔顺或审美重心作为评测标准。
